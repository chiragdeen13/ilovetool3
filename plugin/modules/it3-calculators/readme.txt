== Installation ==

1. WP Admin > Plugins > Add New > Upload Plugin > it3-calculators.zip > Install > Activate
2. WP Admin > IT3 Tools > click "Create All Tool Pages"
3. Done! All 18 tools get their own separate pages automatically.
