16. UUID Generator
17. Color Converter (HEX/RGB/HSL)

== Installation ==

1. WP Admin > Plugins > Add New > Upload Plugin > multytools.zip > Install > Activate
2. WP Admin > MultyTools > click "Create All Tool Pages"
3. Done! All 17 tools get their own pages automatically.
