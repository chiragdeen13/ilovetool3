Auto-adds SEO articles, banner images and FAQs below every tool page.

== What It Does ==

For EVERY tool page automatically:

1. Banner Image - unique SVG generated per tool (emoji + gradient + title)
2. About Section - unique article content per known tool (36+ custom articles)
3. How to Use - step-by-step numbered guide
4. Key Features - checkmark bullet list
5. Why Choose Us - trust-building section
6. FAQ Section - interactive accordion (3 FAQs each)
7. FAQ Schema - JSON-LD structured data for Google Rich Results

Unknown/new tools get smart category-based articles automatically!

== Works With ==

- iLoveTool3 Calculators plugin pages
- MultyTools plugin pages
- IMEI Check pages
- ANY page you create (Claude tools etc.) via smart category templates

== Installation ==

1. Upload and activate
2. Done! Articles appear automatically below every tool page content

== Admin ==

WP Admin > Essential Pages > Tool Articles shows which pages have
custom vs auto-template articles.
